# 油猴脚本

1. 在 Chrome 或 Edge 安装 Tampermonkey。
2. 打开 `<安装目录>\external-player-weblab-safe.user.js`，或把该文件拖进浏览器窗口。
3. Tampermonkey 出现安装页后确认安装。
4. 脚本名称保持原来的 External Player 命名空间，会覆盖旧版本，不应出现两个 `W` 按钮。
5. 禁用或删除旧的 lite/1.4.x 副本，只保留当前 WebLab Safe `1.5.3`。

脚本只负责从网页发起 `ush-weblab://` 调用，不会把 Cookie 塞进网页协议。Cookie Sync 扩展
与 Native Host 使用独立本地通道，因此浏览器和播放器之间不会传递明文登录信息。

测试步骤：

1. 打开 Bilibili、YouTube 或 Twitch 的视频/直播页面。
2. 页面出现 `W` 按钮后点击，或直接按键盘 `W`。
3. 浏览器首次询问是否打开外部应用时选择允许。
4. MPV.NET 应从本包安装目录启动。
