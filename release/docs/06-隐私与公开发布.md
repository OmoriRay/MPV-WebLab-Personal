# 隐私与公开发布

## 绝不能上传的内容

Cookie 等同于登录凭据。以下目录和文件只属于当前设备，不能提交 Git、放入 Release、
发给别人或在截图中展示内容：

```text
credentials\
cache\
temp\
portable_config\watch_later\
portable_config\bilibili-cookies.txt
```

构建器使用白名单复制，发布验证器还会拒绝 Cookie、缓存、日志、PDB、测试记录器、
观看历史和当前 Windows 用户路径。`portable_config\settings.xml` 中的最近播放列表也会清空，
但窗口尺寸、音量等个人偏好保留。

## GitHub 推荐方式

- Git 仓库：只提交源代码、`release/` 脚本、教程、配置和许可证说明。
- GitHub Release：上传 `.7z` 懒人包、扩展 ZIP、油猴脚本和 `SHA256SUMS.txt`。
- 不要把约 1 GB 的播放器二进制直接 `git add`；普通 GitHub Git 对大文件有限制，也会让
  每次克隆都背上历史包袱。
- 在第三方许可证与对应源码义务完全核对前，先使用私有仓库。

## 本地构建命令

```powershell
powershell -ExecutionPolicy Bypass -File ".\release\scripts\Build-Release.ps1" `
  -Version "1.0.2" `
  -SourceRoot "D:\Apps\MPV-WebLab"
```

输出默认位于仓库外侧的 D 盘 `release-output`，不会使用 C 盘作为 staging。生成后仍应检查
`SHA256SUMS.txt`，并在一台没有旧配置的 Windows 设备上做首次安装测试。
