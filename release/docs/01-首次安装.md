# 首次安装

## 系统要求

- Windows 10/11 x64。
- Chrome 或 Edge；Firefox 不在本项目支持范围内。
- 建议安装 Node.js。没有 Node.js 时播放器仍可打开本地视频，但部分 YouTube 提取可能受限。
- 播放 YouTube 时，当前预设会沿用 `http://127.0.0.1:7897` 代理；新设备应确保该代理可用，
  或在安装时用 `-ProxyUrl ""` 清空。

## 一键安装

1. 从 GitHub Release 下载 `MPV-WebLab-personal-<版本>-win-x64.7z` 和
   `SHA256SUMS.txt`。
2. 用 7-Zip 完整解压；不要在压缩包预览窗口里直接运行脚本。
3. 双击 `开始安装.cmd`。
4. 安装器会复制播放器、按当前设备生成路径配置，并注册：
   - `ush-weblab://`；
   - 兼容旧网页脚本的 `ush://`；
   - Chrome/Edge Native Messaging Host；
   - Windows“打开方式”中的 MPV WebLab。
5. 安装结束会自动运行自检。

默认优先使用 `D:\Apps\MPV-WebLab`。如果设备没有 D 盘，默认目录是
`%LOCALAPPDATA%\MPV-WebLab`。也可以指定任意目录：

```powershell
powershell -ExecutionPolicy Bypass -File ".\installer\Install-MPVWebLab.ps1" `
  -InstallRoot "F:\Apps\MPV-WebLab"
```

如果新设备没有 `127.0.0.1:7897` 代理，安装时清空代理设置：

```powershell
powershell -ExecutionPolicy Bypass -File ".\installer\Install-MPVWebLab.ps1" `
  -ProxyUrl ""
```

直播时移缓存默认沿用 `E:\.mpv-bilibili-timeshift`。没有 E 盘时自动回退到
`<安装目录>\cache\bilibili-timeshift`，也可使用 `-TimeshiftCacheRoot` 指定。

## 本地视频关联

安装器会让 MPV WebLab 出现在 Windows 的“打开方式”列表中，但 Windows 10/11 不允许普通
安装脚本绕过用户选择直接改写受保护的默认应用。首次打开 `.mkv` 或 `.mp4` 时，选择
“打开方式 → MPV WebLab → 始终使用”即可。

## 校验下载

在 Release 文件所在目录运行：

```powershell
Get-FileHash ".\MPV-WebLab-personal-1.0.2-win-x64.7z" -Algorithm SHA256
```

结果应与 `SHA256SUMS.txt` 完全一致。
