# 更新与卸载

## 更新

1. 下载并完整解压新版 Release。
2. 关闭所有从 MPV WebLab 目录启动的 MPV.NET 窗口。
3. 在新版解压目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\installer\Update-MPVWebLab.ps1"
```

更新器会替换播放器与脚本，同时保留：

- `credentials` 中由本机生成的 Cookie；
- `cache`；
- `portable_config\watch_later` 播放进度；
- `persistent_config.json` 播放状态；
- 弹幕开关状态；
- 右键下载按钮选择的下载目录。

扩展目录不变时，Chrome/Edge 通常不需要重装，只需在扩展管理页点击一次“重新加载”。
油猴脚本需要打开新版 `.user.js` 文件确认更新。

## 只注销，不删文件

```powershell
powershell -ExecutionPolicy Bypass -File "<安装目录>\maintenance\installer\Uninstall-MPVWebLab.ps1"
```

这只会移除协议、Native Host 和“打开方式”注册，播放器、Cookie 和缓存仍保留。

## 连同私人数据彻底删除

```powershell
powershell -ExecutionPolicy Bypass -File "<安装目录>\maintenance\installer\Uninstall-MPVWebLab.ps1" `
  -RemoveFiles -RemoveUserData
```

这会删除 Cookie、缓存和观看进度，无法恢复。删除浏览器中的扩展和油猴脚本仍需在对应
扩展管理页面手动完成。
