# 故障排查

## 先运行自检

```powershell
powershell -ExecutionPolicy Bypass -File "<安装目录>\maintenance\installer\Test-MPVWebLab.ps1"
```

英文报错 `MPV WebLab verification failed` 的含义是“MPV WebLab 自检失败”。表格中
`Passed=False` 的必选项就是需要修复的环节。

## 网页按 W 没反应

- 确认 Tampermonkey 里只启用了一个 WebLab Safe 脚本。
- 确认浏览器第一次调用外部应用时没有选择永久阻止。
- 自检应显示 `registry:ush-weblab=True` 和 `registry:ush=True`。
- 不要同时保留旧 `D:\Apps\MPV` 的协议处理器。

## YouTube 很慢或打不开

- 当前个人预设沿用 `http://127.0.0.1:7897`。确认本机代理程序正在监听该端口。
- 不使用代理时，重新运行安装脚本并传入 `-ProxyUrl ""`。
- 安装 Node.js 后重新运行安装器，让 wrapper 记录正确的 Node 路径。
- 打开 Cookie Sync 扩展状态页，确认 YouTube Cookie 已在本机刷新。

## Bilibili 只有部分画质

- 登录 Bilibili 后重新点击 Cookie Sync 扩展。
- 确认 `<安装目录>\credentials\bilibili-cookies.txt` 在本机生成。
- Cookie 过期时重新同步，不要从另一台设备复制 Cookie 文件。

## 扩展显示 Native Host 不可用

- 先运行自检。
- 确认扩展 ID 是 `mkfocliccanidollbpnmaedkbmadjdai`。
- Chrome/Edge 扩展页面点击“重新加载”。
- 如果移动了整个安装目录，必须从 Release 重新运行安装器，不能只拖动文件夹。

## 直播时移缓存失败

- 有 E 盘时默认写到 `E:\.mpv-bilibili-timeshift`。
- 没有 E 盘时写到 `<安装目录>\cache\bilibili-timeshift`。
- 检查目标磁盘剩余空间和写入权限。
